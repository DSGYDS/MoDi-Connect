## Variant: 产品级 UI v1

### 设计立场
参照高端音频设备控制面板的视觉语言，走专业、干净、可信赖的方向，避免工程工具感。

### 关键选择
- **布局**：220px 侧边栏 + 内容区，1280×720 窗口
- **色彩**：主绿 `#00C389` / 深色背景 `#111618` / 卡片 `#171D20` / 边框 `#2A3438`
- **字号**：标题 20px SemiBold / 卡片标题 16px Medium / 正文 14px / 辅助 12px
- **圆角**：大卡片 16px / 按钮 10px / 小卡片 12px
- **阴影**：`0 8px 40px rgba(0,0,0,0.4)` 窗口阴影，卡片无阴影

### 交互
- 深色/浅色主题切换（侧边栏底部按钮）
- 四模式卡片点击切换（active 状态绿色边框 + 背景）
- 连接状态呼吸动画（2s loop）
- 波形动画（60FPS）
- hover 缩放效果（150ms scale 0.98）
