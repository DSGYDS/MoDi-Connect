# 历史工程资料

`archive` 保存对追溯仍有价值、但不参与当前应用构建的资料。

| 目录 | 内容 | 是否参与当前构建 |
|---|---|---|
| `ui-prototypes` | Android/Windows 早期 HTML UI 原型 | 否 |
| `ui-validation-history` | 早期舞台截图、反馈图、稳定性输出和完整旧验收记录 | 否 |
| `legacy` | Wi-Fi Direct PoC、旧 WPF PoC UI 和早期 HTML 草图 | 否 |
| `memory-logs` | 历史开发记录 | 否 |

仓库不保存或再分发 VB-CABLE 等第三方驱动二进制。需要虚拟音频驱动时，应用只检查安装状态并引导用户访问厂商官方页面。

当前源码、文档和验收入口见 [根目录 README](../README.md) 和 [文档总索引](../docs/README.md)。
