### 已知问题（阻塞项）

**问题：驱动加载失败，错误码 0xC000026C（STATUS_UNABLE_TO_LOAD_DRIVER）**

- 现象：devcon status 显示 problem 39，设备管理器不出现音频端点
- 确认 testsigning=Yes, nointegritychecks=Yes, SecureBoot=False
- 确认 .sys 文件存在于 DriverStore 目录
- 原版 Sysvad（未修改 minwavertstream.cpp）可以正常加载
- 加入 VirtualCable 环形缓冲代码后驱动无法加载

**排查方向：**

1. ~~全局 C++ 对象构造函数~~ → 已改为指针延迟初始化，仍失败
2. `new (NonPagedPoolNx, 'CVM') CVirtualCable()` 语法可能与 Sysvad 的 NewDelete.h 冲突
3. VirtualCable.h 中的 `ExAllocatePool2` 在 Init() 中调用，但 Init 在 PASSIVE_LEVEL 应该没问题
4. 可能是链接器问题：新增的 .cpp 代码引入了未解析的外部符号
5. **最可能原因**：需要逐步二分排查——先只加 DMA 清零（不加 VirtualCable），确认能加载后再加 VirtualCable

### 部署流程踩坑记录

| 坑 | 原因 | 解决 |
|----|------|------|
| pnputil 报"不包含数字签名信息" | INF 缺 .cat 文件 | makecat + signtool 签名 |
| pnputil 报"找不到文件" | INF 引用 keywordDetector DLL | 删除所有 keyword 相关行 |
| pnputil 不复制 .sys | 未 cd 到 .sys 所在目录 | 必须 cd 到 Debug 目录再执行 |
| DriverStore 拒绝写入 | TrustedInstaller 保护 | takeown + icacls 提权 |
| 重启后权限重置 | Windows 重置 DriverStore ACL | 每次重启后需重新 takeown |
| 多个设备实例残留 | 多次 devcon install | 需 devcon remove 所有旧实例 |

## 四、正确的开发步骤（下次继续时按此执行）

### Step 1：最小化验证（确认基础能加载）

1. 还原 minwavertstream.cpp 为原版（git checkout 或备份恢复）
2. 只做端点裁剪（minipairs.h）+ INF 改名
3. 编译 → 部署 → 确认设备 OK
4. **这一步不做任何数据通路修改**

### Step 2：加入 DMA 清零

1. 只在 MapAllocatedPages 后加 `RtlZeroMemory`
2. 编译 → 部署 → 确认设备仍 OK
3. 如果失败 → RtlZeroMemory 有问题（不太可能）

### Step 3：加入 VirtualCable（核心难点）

1. 创建 VirtualCable.h（环形缓冲类）
2. 在 minwavertstream.cpp 中用**纯 C 风格**实现全局缓冲：
   ```c
   // 不要用 C++ class，改用纯 C 结构体 + 函数
   static BYTE* g_VirtualCableBuffer = NULL;
   static ULONG g_VcbWritePos = 0;
   static ULONG g_VcbReadPos = 0;
   static ULONG g_VcbDataAvailable = 0;
   static KSPIN_LOCK g_VcbSpinLock;
   ```
3. 在 Stream Init 中用 `ExAllocatePool2` 分配缓冲
4. 在 render 路径写入，capture 路径读出
5. 编译 → 部署 → 确认设备 OK

### Step 4：端到端验证

1. 设置 MoDi 扬声器为默认播放
2. 播放音乐
3. 用 Audacity 从 "MoDi Virtual Mic" 录音
4. 确认录到的是播放的音乐

### Step 5：App 适配

1. CableRenderer.cs 设备匹配改为优先 "MoDi"
2. 手机推流 → 路线 3/4 → 确认虚拟麦克风输出

## 五、部署命令速查（管理员终端）

```powershell
# 0. 前置（每次重启后如果权限被重置）
$dst = "C:\Windows\System32\DriverStore\FileRepository\componentizedaudiosample.inf_amd64_2985293697a3b7b5"
takeown /f $dst /r /d y
icacls $dst /grant Administrators:F /t

# 1. 编译
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\amd64\MSBuild.exe" "d:\LAN-Audio-Bridge\sysvad-dev\TabletAudioSample\TabletAudioSample.vcxproj" /p:Configuration=Debug /p:Platform=x64

# 2. 清理 INF（删除 keyword detector 引用）
$inf = "d:\LAN-Audio-Bridge\sysvad-dev\TabletAudioSample\x64\Debug\ComponentizedAudioSample.inf"
$lines = [System.IO.File]::ReadAllLines($inf)
$filtered = $lines | Where-Object { $_ -notmatch '(?i)keyworddetector|KEYWORDDETECTORCONTOSOADAPTER' }
[System.IO.File]::WriteAllLines($inf, $filtered)

# 3. 生成 + 签名 .cat
$dir = "d:\LAN-Audio-Bridge\sysvad-dev\TabletAudioSample\x64\Debug"
& "C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\makecat.exe" -v "$dir\sysvad.cdf"
& "C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\signtool.exe" sign /sha1 "E33C0E4A4C78D8097967B82F83EF89A32ECFF69A" /fd SHA256 "$dir\sysvad.cat"

# 4. 复制到驱动商店
Copy-Item "$dir\TabletAudioSample.sys" $dst -Force
Copy-Item "$dir\sysvad.cat" $dst -Force
Copy-Item "$dir\ComponentizedAudioSample.inf" $dst -Force

# 5. 重启或热重载
& "C:\Program Files (x86)\Windows Kits\10\Tools\10.0.26100.0\x64\devcon.exe" disable "Root\sysvad_ComponentizedAudioSample"
& "C:\Program Files (x86)\Windows Kits\10\Tools\10.0.26100.0\x64\devcon.exe" enable "Root\sysvad_ComponentizedAudioSample"

# 6. 检查状态
& "C:\Program Files (x86)\Windows Kits\10\Tools\10.0.26100.0\x64\devcon.exe" status "Root\sysvad_ComponentizedAudioSample"
```

## 七、注意事项

- 测试签名必须开启：`bcdedit /set testsigning on` + `bcdedit /set nointegritychecks on`
- 每次编译后 INF 会被重新生成（keyword detector 回来），必须重新清理
- DriverStore 权限每次重启后重置，需重新 takeown
- 避免使用全局 C++ 对象（构造函数在驱动加载时执行，可能导致失败）
- 优先使用纯 C 风格代码（静态变量 + 函数），避免 C++ 初始化顺序问题
